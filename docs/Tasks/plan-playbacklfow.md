Цель: Создать диаграмму последовательности, описывающую процесс того, как пользователь запрашивает и получает видеоконтент для просмотра.

User Review Required
Пожалуйста, ознакомьтесь с предложенными ниже шагами, которые будут отражены на диаграмме. Если всё верно (включая логику проверки подписки, работу через CDN и сохранение событий прогресса просмотра в Kafka), подтвердите, и я сгенерирую диаграмму.

Proposed Changes
[NEW] 
docs/PlaybackFlow.puml
Будет создан новый PlantUML файл с диаграммой последовательности, включающий следующие этапы:

Запрос доступа: Клиент (Web, Mobile, Smart TV) запрашивает доступ к видео через API Gateway к Content Service.
Проверка прав: Опциональная проверка подписки или факта покупки (интеграция с Subscriptions/Payments Service).
Генерация HLS/DASH URL: Возврат подписанной ссылки (Signed URL) на Amazon CloudFront для безопасного доступа к медиа-сегментам.
Стриминг контента: Клиент запрашивает видеосегменты и манифесты напрямую у CDN.
Телеметрия (Прогресс просмотра): Раз в несколько минут (или при закрытии плеера) клиент отправляет прогресс просмотра в Content Service.
Шина событий (Kafka): Content Service публикует событие PlaybackProgress / PlaybackFinished в Apache Kafka.
Асинхронное сохранение: Events Service (и потенциально другие сервисы) вычитывает это событие для сохранения статистики.
